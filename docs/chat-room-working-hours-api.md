# 교사 근무시간 상태 조회 API

- 엔드포인트: `GET /chat-rooms/working-hours`
- 목적: 학부모에게 매핑된 교사가 현재 근무시간 이내인지 공통으로 조회
- 부수 동작: 없음

## 요청

- 헤더
  - `Authorization: Bearer {JWT}`

## 처리 규칙

1. JWT로 로그인한 사용자를 확인한다.
2. 로그인 사용자가 학부모(`PARENT`)인지 확인한다.
3. 해당 학부모와 연결된 학생 1명, 담임 교사 1명이 존재하는지 확인한다.
4. 현재 시각을 `Asia/Seoul` 기준으로 계산한다.
5. 담임 교사의 근무시간 설정에서 오늘 요일과 현재 시각이 포함되는지 확인한다.
6. 근무시간 설정이 없거나 현재 시각이 포함되지 않으면 `false`를 반환한다.

## 응답

```json
{
  "success": true,
  "code": 200,
  "message": "교사 근무시간 정보 조회에 성공했습니다.",
  "data": {
    "isInWorkingHours": true
  }
}
```

## 응답 필드

- `data.isInWorkingHours` (boolean)
  - 현재 시각이 담임 교사의 근무시간에 포함되는지 여부

## 오류 응답

- `403 Forbidden`
  - 학부모 계정이 아닌 경우
- `404 Not Found`
  - 사용자, 연결된 학생, 학급, 담임 교사 정보를 찾을 수 없는 경우

## 비고

- 현재 MVP 정책상 학부모는 학생 1명, 담임 교사 1명과 연결된 것으로 가정한다.
