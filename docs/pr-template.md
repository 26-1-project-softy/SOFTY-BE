# PR 템플릿

아래 마크다운을 복사해서 PR 본문에 사용합니다.

```md
## 작업 내용

- 작업 배경과 목적을 한두 줄로 적어주세요.
- 이번 PR에서 해결하는 문제를 간단히 적어주세요.
- 필요하면 문서/설정 변경 여부도 함께 적어주세요.

## 주요 변경 사항

- 변경한 핵심 구현 내용을 항목별로 적어주세요.
- 추가한 API, 서비스, DTO, 엔티티, 쿼리 등을 구체적으로 적어주세요.
- 정책 변경이나 예외 처리 기준이 바뀌었다면 함께 적어주세요.
- 문서 반영이 있으면 관련 파일 경로를 적어주세요.

## 기대 효과

- 이 변경으로 사용자나 운영 측면에서 좋아지는 점을 적어주세요.
- 데이터 정합성, 유지보수성, 확장성 측면의 효과가 있으면 적어주세요.

## 참고

- 리뷰어가 알면 좋은 전제나 제한사항을 적어주세요.
- 연동 API, 환경변수, 후속 작업, 테스트 방법 등을 적어주세요.
```

## 작성 가이드

- `작업 내용`: 왜 이 PR이 필요한지 설명합니다.
- `주요 변경 사항`: 실제 코드 변경점을 리뷰어가 빠르게 파악할 수 있게 적습니다.
- `기대 효과`: 변경 결과 어떤 문제가 줄고 무엇이 좋아지는지 적습니다.
- `참고`: 아직 남아 있는 이슈, 운영 전제, 테스트 포인트를 적습니다.
